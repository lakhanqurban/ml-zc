## Q7. Sum of weights (Linear Regression)

**Answer: 0.369**

Implementation steps:

1. Select cars from Asia: `df[df['origin'] == 'Asia']`
2. Select columns `vehicle_weight` and `model_year`
3. Take first 7 rows: `.head(7)`
4. Convert to NumPy array `X`
5. Compute `XTX = X.T @ X`
6. Invert: `XTX_inv = np.linalg.inv(XTX)`
7. Create `y = [1100, 1300, 800, 900, 1000, 1100, 1200]`
8. Compute weights: `w = XTX_inv @ X.T @ y`
9. Sum of elements in `w`: **0.3692 ≈ 0.369**

This implements the normal equation for linear regression: `w = (X^T X)^{-1} X^T y`
