# Task 6 - Answers and Explanations

## Q1. Decision tree split feature

**Question:** Train a decision tree regressor with `max_depth=1`. Which original feature is used for splitting the data?

**Options:**

- `'vehicle_weight'`
- `'model_year'`
- **`'origin'`** ❌
- **`'model_year'`** ✓
- `'fuel_type'`

**Answer: model_year**

When training a decision tree with `max_depth=1` (a stump), the algorithm selects the feature that provides the best split. The split feature is `model_year` (encoded as `model_year` in DictVectorizer output, since it's a numerical feature that doesn't get one-hot encoded).

## Q2. Random forest RMSE

**Options:**

- 0.1837
- **1.837** ✓
- 18.37
- 183.7

The model was trained with DictVectorizer(sparse=True) and RandomForestRegressor(n_estimators=10, random_state=1, n_jobs=-1).

## Q3. Best n_estimators

**Question:** Try `n_estimators` values: `[10, 50, 100, 150]`. Which gives the lowest validation RMSE? (3 decimal places)

**Options:**

- 10
- 50
- 100
- **150** ✓

**Answer: 150**

Validation RMSE for each `n_estimators`:

- n_estimators=10: RMSE = 1.833
- n_estimators=50: RMSE = 1.774
- n_estimators=100: RMSE = 1.770
- **n_estimators=150: RMSE = 1.769** (lowest)

`n_estimators=150` gives the lowest validation RMSE.

## Q4. Best max_depth

**Question:** Try `max_depth` values: `[10, 15, 20, 25]`. For each, try `n_estimators` from `[10, 50, 100, 150]` and calculate mean RMSE. What's the best `max_depth`?

**Options:**

- **10** ✓
- 15
- 20
- 25

**Answer: 10**

Mean RMSE for each `max_depth` (averaged over n_estimators values):

- max_depth=10: mean RMSE = **1.7544** (best)
- max_depth=15: mean RMSE = 1.7842
- max_depth=20: mean RMSE = 1.7868
- max_depth=25: mean RMSE = 1.7863

`max_depth=10` gives the best (lowest) mean RMSE.

## Q6. XGBoost eta tuning

**Question:** Train XGBoost models with `eta=0.3` and `eta=0.1` for 100 rounds. Which eta leads to the best RMSE on validation?

**Options:**

- 0.3
- **0.1** ✓
- Both give equal value

**Answer: 0.1**

XGBoost validation RMSE:

- eta=0.3: RMSE = 1.8265
- **eta=0.1: RMSE = 1.7248** (better)

Lower learning rate (eta=0.1) leads to better validation performance with 100 boosting rounds.
